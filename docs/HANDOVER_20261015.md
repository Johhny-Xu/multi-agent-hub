## 二、已实施变更详解

### A. 品牌 Logo 常驻 + 顶栏/活动栏智能收展（`b6c9705` / `bdee187`）

**HTML**：`<body>` 开头、`#app-bg-layer` 之后注入锚点（**不要把 base64 再抄一份**）：

```html
<div id="brand-logo-pin" class="brand-logo-pin" role="button" tabindex="0"
     aria-label="multi-agent-hub 品牌锚点"
     title="multi-agent-hub · 点击切换顶栏与活动栏的常驻 / 自动收展"></div>
```
JS 用 `cloneNode` 把 `header.top .brand-logo img` 挂进去（`mountBrandLogoPin()`）。

**引擎**（`setupChromeAutoHideEngine()`，紧跟 `setupSidebarHoverEngine()` 之后）：

| 参数 | 值 | 说明 |
|---|---|---|
| `CHROME_EDGE_Y` | 38 | 光标 Y ≤ 38px 展开顶栏 |
| `CHROME_EDGE_X` | 42 | 光标 X ≤ 42px 展开活动栏 |
| `CHROME_EXPAND_DELAY` | 90 | 命中边缘后的展开延时（防过路误触） |
| `CHROME_COLLAPSE_DELAY` | 650 | 离开后的舒适防抖收起延时 |

- 顶栏 `header.top.collapsed-row`、活动栏 `.cb-activity-bar.collapsed-col`，动画走既有 `transition`（0.32s margin/transform + 0.24s opacity）。
- 禁用收起的条件（`chromeBusy()`）：`<dialog id="modal">` 打开、任一 `.export-dropdown-menu` / `#model-popover-panel` / `#status-bar-config-panel` 未 hidden、`header.top` 内有输入焦点。
- 点 Logo 切「自动 / 常驻」，持久化 `localStorage.agent_hub_chrome_autohide`；常驻态 `body.chrome-pinned` 给 Logo 加主题色描边。
- ≤859px（手机端）不启用。

**Logo 永不隐藏**：锚点是 `position: fixed; z-index: 120`，独立于顶栏的 `collapsed-row`（其 `pointer-events:none` 影响不到锚点）。

**Logo 与活动栏首项的重叠**：顶栏收起后 Logo 正好压住活动栏第一个 tab → `body.header-collapsed .cb-activity-bar { padding-top: 50px }`（含过渡）。

**对话列表展开时活动栏常驻**（`9b1c578`，第 10 项需求）：
侧栏热区是 `x ≤ 324`、活动栏热区只有 `x ≤ 42`，光标停在侧栏上（如 x=150）时侧栏展开、活动栏却会收起 → 布局跳动且点不到标签页。现：
- `chromeCanCollapse(which)` 加参数：`which === 'actbar' && chromeSidebarExpanded()` → 一律不许收；
- `chromeSyncActbarWithSidebar()` 在 `togglePlatformsSidebar()` 展开侧栏的**瞬间**把活动栏拉回（不等防抖）。

### B. 侧栏展开触发范围改为「红框」（`6697dcb`，第 7 项）

原逻辑不对称：收起时只认 `actBar.right + 14px`（必须贴最左），展开后却认 `actBar.right + 280px`。
现统一为：
```js
var revealRight = actRect.right + getSidebarRevealWidth();
inZoneX = isCollapsed ? (x <= revealRight) : (x <= Math.max(sbRect.right, revealRight));
```
`getSidebarRevealWidth()` 展开时实时量宽并缓存，收起时（宽度为 0）回退 `268px`（与 `.cb-platforms-sidebar { width: 268px }` 对齐）。展开/收起定时器触发前都用 `lastPointer` 复核真实光标位置，避免 `mouseleave` 早于最后一次 `mousemove` 造成误收起。1440 视口下触发边界 = **324px**。

### C. 自定义背景色号统一（`e68c10f`，第 3 项）

在 `body.has-custom-bg` 作用域内把基础中性灰面整体并入卡片色号：

```css
body.has-custom-bg {
  --gem-bg-canvas / --gem-bg-sidebar / --gem-bg-card-inner / --gem-surface-low
  / --gem-surface-highest / --mcode-bg / --mcode-bg-primary / --mcode-bg-secondary
  / --mcode-surface / --mcode-surface-muted / --mcode-surface-raised
  / --mcode-code-bg / --studio-bg / --studio-bg-elevated / --studio-surface
    → var(--gem-bg-card);
```

**`--gem-surface-high` 是唯一例外（用户明确要求「灰色的地方不变」）**：这一层灰是交互态、`.qa-bar` 配额进度条轨道、列表选中行底色的载体，改成纯白会让它们在白底上消失。实测模型列表选中行底色恢复 `rgb(204,208,218)` = `#ccd0da`。

### E. 色系预设 2 → 6 个（`ad70f6a`，第 8 项）

新增 **Aurora 极光微光 `#0B0F19` / Dusk 暮霭流金 `#18121D` / Cyber 赛博深空 `#070913` / Grid 科技网格 `#0A0F1E`**。

```js
bgLayer.style.backgroundImage  = 'var(--preset-bg)';
bgLayer.style.backgroundSize   = 'var(--preset-bg-size, cover)';
bgLayer.style.backgroundRepeat = 'var(--preset-bg-repeat, no-repeat)';
bgLayer.style.backgroundPosition = 'var(--preset-bg-position, center)';
```

## 三、必须记住的技术机制与坑

### 1. CSS 自定义属性的「别名在声明处完成替换」
`--mcode-*` 系列在预设主题块里写成 `--mcode-x: var(--gem-y)`，而替换发生在**声明所在元素（`<html>`）**上，然后逐层继承。
→ **在 `body.has-custom-bg` 上只改 `--gem-y` 对 `--mcode-x` 无效，必须把别名也显式重映射。**
→ 反过来用也成立：新增预设只需覆写 `--gem-*`，别名会自动跟随，**不要重复声明**。

### 2. 特异性踩坑清单（本项目已中招 4 次）
| 现象 | 原因 |
|---|---|
| 元素移了但周围没跟着移 | 基础规则的简写属性（`margin: 0`）压掉状态规则的长写属性（`margin-left`） |
| 写了避让边距却没生效 | 选择器的**祖先关系不成立**（把子节点写成了兄弟节点） |
| 组件自身 padding/radius/height 无效 | 全局 `input[type="text"]`(0,1,1) 压掉单类选择器(0,1,0) |
| 引用了一个从没定义过的 CSS 变量 | 深色主题下回退值（近白色）恰好正常，浅色主题才暴露 |

### 3. 「引用了不存在的 CSS 变量」体检命令
```powershell
python - <<'PY'
import re
src = open('console/client/index.html', encoding='utf-8').read()
css = re.search(r'<style>(.*?)</style>', src, re.S).group(1)
used = set(re.findall(r'var\((--[a-z0-9-]+)', css))
defined = set(re.findall(r'(--[a-z0-9-]+)\s*:', css))
print('undefined:', sorted(used - defined))
PY
```
当前结果：66 个色号被使用，未定义的只剩 `--gem-accent` / `--gem-hover` / `--mono` / `--sans`（均有无害回退）。
