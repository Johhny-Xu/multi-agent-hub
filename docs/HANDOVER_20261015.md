## 1. 本轮交付总览与版本基线

本轮（2026-10-14 ~ 2026-10-15）工作重点由底层的鉴权与通信协议，推进至**前端交互深度打磨、视觉一致性对齐、调色板矩阵重构、微交互动效补全、自定义壁纸全局毛玻璃通透以及零依赖演示 Demo 的封装分发**。

### 核心里程碑成果：
1. **视觉一致性与品牌 R 角标准化**：以品牌 Logo 的圆角曲率比例为基准规范全站 Squircle（平滑圆角矩形），解决全站 R 角不一致及 ZCode 插件图标丢失问题。
2. **模型选择弹出层与思考强度精炼**：实现根据点击位置（左/右侧）动态计算弹窗朝向与贴靠对齐；精简思考深度标签格式为 `模型名 · 思考档位`。
3. **动效断层修复**：彻底重构会话列表与侧边栏折叠逻辑，消除由于 DOM 重新渲染带来的卡顿和生硬瞬跳，实现顺滑的 CSS 展开收起动效。
4. **气泡工具栏重塑**：彻底剥离顶部冗余的操作按钮（`↻ 填入`、`复制`），改为气泡底角的独立极简 SVG 图标按钮（Agent 居左下、User 居右下），配备即时复制反馈微动效。
5. **左上角头像拉伸根因彻底消除**：击破全局 `button { min-height: 32px }` 的盒模型穿透，双重锁定 `24px × 24px` 正方形与 `1:1` 宽高比。
6. **零依赖可交互 Demo 打包体系**：实现一键将完整 WebUI 打包为带内存虚拟引擎、虚拟模型与账号、无任何后端依赖的独立 HTML 文件（可直接双击脱机运行与分享演示）。
7. **背景预设与专属深浅调色板矩阵**：清理 4 个旧杂乱背景，专注 Mocha 与 Shell 两大色系；为 Mocha（Dark `#1e1e2e` / Latte `#eff1f5`）与 Shell（Dark `#0f0f11` / Paper `#f8f9fa`）量身定制专属深浅色，消除会话框脱节违和感。
8. **智能侧栏悬浮收展引擎**：引入现代 IDE 级别非对称延迟与光标存在感知（180ms 靠近展开 + 650ms 移出防抖收缩 + 搜索焦点锁定），彻底剔除机械点击生硬感。
9. **自定义壁纸全局毛玻璃通透体系与会话框透明适配**：当未上传图片时默认保持原生纯净白极简底色；一旦应用真实壁纸图片，会话框主视口、底栏悬浮 Composer、用户消息气泡、顶栏 Navigation、会话顶部标题栏、右侧 Antigravity 工作台及左侧侧边栏全部切换为半透明毛玻璃态，消除突兀大白块遮挡，让壁纸画面自然通透贯穿整个主视觉界面。

## 3. 纯前端独立交互 Demo 架构与虚拟化引擎

为满足免安装、免环境配置、零后台依赖的交互演示需求，本项目设计了独立且可扩展的纯前端 Demo 构建管道。

```
│ console/client/index.html │  +  │  scripts/demo_engine.js   │
│      (原始控制台页面)      │     │    (内存虚拟驱动引擎)     │
└─────────────┬─────────────┘     └─────────────┬─────────────┘
              │                                 │
              └────────────────┬────────────────┘
                               │
                     python scripts/build_demo.py
                               │
                               ▼
        ┌─────────────────────────────────────────────────┐
        │  单文件零依赖独立 Demo 产物 (无网络请求、零报错)  │
        ├─────────────────────────────────────────────────┤
        │ • demo.html (仓库根目录)                         │
        │ • demo/index.html (静态服务器目录)              │
        │ • C:\Users\...\Desktop\multi-agent-hub-demo.html│
        └─────────────────────────────────────────────────┘
```

### 3.1 虚拟化引擎核心原理 (`scripts/demo_engine.js`)
1. **全局接口全面拦截**：在页面 `<head>` 顶部注入，早于任何业务代码运行；重写全局 `window.fetch` 与 `window.EventSource`（SSE）。
2. **虚拟账号体系 (`mockAccountsData`)**：
   - 包含 9 大 Worker 的虚拟化账号（如 Antigravity Pro 订阅号、CodeArts 企业主账号、CodeBuddy 国际/国内独立账号、MiniMax 白金开发者等）。

3. **虚拟模型与思考档位体系 (`mockWorkersModelsData`)**：
   - 为每个 Worker 配置符合官方当季规格的模型列表（如 `Gemini 2.5 Pro (1M)`、`Claude 3.7 Sonnet`、`DeepSeek-R1`、`MiniMax-M3` 等）。
   - 内置思考强度调节（关闭 / 低 / 中 / 高 / 深度思考），支持底栏无缝切换。
4. **流式会话与思考链仿真**：
   - 预设经典场景会话，发送消息后触发打字机仿真流式输出。
   - 自动模拟思考过程提取，渲染现代化折叠框与耗时统计。
   - 所有交互均在纯前端内存中闭环，浏览器 Console **0 报错、0 失败请求**。

## 5. 生产部署、构建与多端同步操作手册 (Runbook)

在项目根目录下执行以下命令即可全自动重新编译打包 Demo：

*执行后将自动更新 `demo.html`、`demo/index.html` 以及 Windows 桌面文件。*

### 5.2 生产服务器同步与服务平滑重载
若修改了前端 WebUI 源码，需将文件推送至 Linux 宿主机并热重载：
```bash
# 1. 拷贝最新控制台文件至远程生产机
scp -o BatchMode=yes console/client/index.html n5095:/home/<user>/agent-hub-console/miniapp/client/index.html

# 2. 热重启控制台 Systemd 服务
ssh -o BatchMode=yes n5095 "systemctl --user restart agent-hub-console"

# 3. 检查服务健康状态
ssh -o BatchMode=yes n5095 "systemctl --user is-active agent-hub-console"
```
*服务重启耗时通常小于 200ms，重启后通过浏览器访问 `http://<hub-host>:8890/dashboard` 即可即时体验最新版本。*

## 7. 常见故障排查指南 (Troubleshooting)

### Q1: 浏览器打开控制台后，发现左上角头像仍有拉伸感？
- **排查手段**：按 `F12` 打开 DevTools，在 Elements 面板选中 `#current-avatar-sm`。
- **确认指标**：
  1. 查看 Computed 属性中 `width` 与 `height` 是否均为 `24px`。
  2. 确认 `min-height` 是否被限制为 `24px`（若显示 32px，说明浏览器命中了强缓存）。
- **解决方式**：按 `Ctrl + F5` 强制刷新浏览器缓存，或检查 `agent-hub-console` 服务是否已正确执行 `systemctl --user restart`。

### Q2: 独立 Demo 打开后点击按钮无响应？
- **排查手段**：按 `F12` 检查 Console 是否有报错。
- **确认指标**：确认页面头部是否存在 `<script id="demo-mock-engine">` 标签。
- **解决方式**：重新运行 `python scripts/build_demo.py` 生成纯净的单文件版本。

### Q3: 侧边栏折叠时出现白边或跳动？
- **排查手段**：检查外层父容器是否遗漏了 `overflow: hidden`。
- **代码核对**：确认 `.sidebar-threads` 以及 `.platform-session-tree` 是否正常应用了 `transition: max-height 0.24s cubic-bezier(0.16, 1, 0.3, 1)`。
