## 四、GitHub 贡献图修复（283 个提交重写）

### 4.1 原因

`multi-agent-hub` 所有提交的作者都是 `agenthub@users.noreply.github.com` —— 这个 noreply 地址**不属于**
`Johhny-Xu`（id `93818419`）。GitHub 只按「提交邮箱 ↔ 账号已验证邮箱」计算贡献，所以一整年都是灰的。
对照：`aicode` 仓库用的是 `93818419+Johhny-Xu@users.noreply.github.com`，那一格才是绿的。

### 4.2 做法

```bash
git clone --mirror . ../mirror-backup.git          # 先备份
git clone --mirror ../mirror-backup.git ../rewrite && cd ../rewrite
git filter-repo --mailmap <(echo 'Johhny-Xu <93818419+Johhny-Xu@users.noreply.github.com> agenthub <agenthub@users.noreply.github.com>')
git push --force <remote> refs/heads/main:refs/heads/main
git push --force <remote> 'refs/tags/*:refs/tags/*'
```

- `git filter-branch` 在 Windows 上约 **6 秒/提交**（283 个要 28 分钟，会被超时杀掉），
  换 `git-filter-repo`（单文件脚本）后 **2.55 秒**写完；
- 19 个 tag 全部 force 重推；`v1.0.18` 现在指 `2aebbae`，11 个 Release 与 8 个资产都还在；
- 文档里 4 处旧 SHA 已随 `commit-map` 换成新值（提交 `c55fb58`）。
