## 二、本轮修复

### 1. Qoder CN「明明没签到却显示已签到」

**现象**：卡片显示「今日已领取」，但 Qoder 客户端里「每天领 100 Credits」的按钮还是可点的。

**根因**：`checkin.mjs` 判定「今日已领」只看 `claimStatus === 'CLAIMED'`，**没有校验活动有效期**。上游返回的列表里带着上一期已领的老活动，于是直接走 `already` 分支，根本不去领今天的。

**修法**（对齐开源项目 `wallechfox/qoder-checkin`）：

```js
// CLAIMED 必须同时满足 startAt <= now < endAt 才算「今日已领」
function qoderInWindow(row, nowSec = Math.floor(Date.now() / 1000)) {
  const s = Number(row?.startAt ?? 0) || 0;
  const e = Number(row?.endAt ?? 0) || 0;
  if (!e) return true;              // 没有窗口字段就不限制，避免判死
  return s <= nowSec && nowSec < e;
}
```

同时把过期 CLAIMED 单独统计，并在消息里带诊断串 `[活动 N 个：CLAIMED/CLAIMABLE…]`，以后排查不用再猜。

**验证**：`POST /api/checkin/run {"platform":"qoder-cn"}` → 两个账号各「领取 1 个活动，+100 Credits」。

### 2. 签到日志点开是空白

**现象**：点「签到日志 (20)」标签，下面什么都没有，直接接下一个卡片。

**根因**：**HTML 少了一个 `</div>`** —— `#checkin-tab-history` 被嵌在 `#checkin-tab-grid` 里面。切到日志 tab 时 JS 给 grid 设 `hidden`，里面的 history 跟着一起被隐藏。DOM 里 `history.parentElement.id === 'checkin-tab-grid'` 就是这个症状的铁证。

**修法**：在 grid 的 `</div>` 后再补一个 `</div>`，让两个 tab content 成为兄弟节点；另加 `.settings-card-body > .checkin-tab-content { width: 100% }` 兜底。

**验证**：切到日志 tab，容器高度 454px、20 条记录正常显示。

### 3. Meoo 头像

头像映射表（`index.html` 里 `code: 'MX'` 那张）加 `meoo`（薄荷绿渐变 + 「秒」），并补 `.platform-avatar[data-agent="meoo"]` 的深底 + 绿描边规则——不加的话会落到「取名字前两位大写」的兜底，显示成 `ME`。

## 三、Meoo（秒悟）接入

### 3.1 它是两套东西

| 形态 | 用途 | 入口 |
| --- | --- | --- |
| **CLI**（`@aliyun-meoo/cli`） | 项目/云服务/部署 | `meoo login/account/projects/deploy/db/fn/...` |
| **Agent OpenAPI** | 跑 Agent 任务（能当子代理） | `https://meoo.com/open/v1` |

**CLI 没有对话能力**（`meoo chat/agent/run` 全是 `unknown command`），所以之前"能不能当子代理"的答案是：**CLI 不行，OpenAPI 行**。

### 3.2 签到（第 7 个平台）

- 每日积分是「每日登录赠送」（账号权益 `typeCode = daily_login`，2000/天），所以签到 = `meoo login --ak` + `meoo account --json`。
- AK 存 `~/.config/agenthub-meoo/meoo-auth.env`（`MEOO_AK=...`，600 权限，**不进仓库**）；也支持 `MEOO_AK` 环境变量或控制台「配置 AK」。
- 两个坑：
  - Windows 上 npm 全局是 `meoo.cmd`，`execFile` 必须 `shell: true`；
  - systemd 的 PATH 里没有 `~/.npm-global/bin`，`resolveMeooBin()` 按绝对路径兜底；同时执行过
    `systemctl --user set-environment PATH=~/.npm-global/bin:...`，让 hub 派生的 worker 也能直接调 `meoo`。

### 3.3 Agent OpenAPI（可当子代理）

```text
POST /open/v1/projects/{project_url_id}/agent/runs
  Authorization: Bearer <meoo_ak>
  { "message": "做一个报名页", "model": "qwen3.8-flash", "speed_tier": "fast|standard|deep", "yolo": true }

GET  /open/v1/projects/{id}/agent/runs/{run_id}/events   → SSE
GET  /open/v1/projects/{id}/agent/capabilities          → 可用模型（必须用返回的 models[].id）
```

- 模型实测可用：`auto` / `qwen3.8-flash` / `qwen3.8-max` / `qwen3.7-plus` / `deepseek-v4.1-flash-1017` / `kimi-k3` / `MiniMax-M3.1-Flash` / `glm-5.3-flash` …
- **用账号 AK 直接调，不需要部署应用**（这点和我早先的判断不同，之前以为只能从部署后的边缘函数里调）。
- 现成脚本：`scripts/meoo_agent_run.mjs`

```bash
node scripts/meoo_agent_run.mjs --project <url_id> --tier fast "只回复两个字：收到"
# → 收到 / ✔ 结束：completed
```

- 项目要先有：`meoo projects create <name>`，`.env` 里会写 `MEOO_PROJECT_URL_ID`（= OpenAPI 里的 `project_id`）。

## 六、红线

- AK / token 一律放 `~/.config/agenthub-*`，**不进仓库、不写进 CHANGELOG**。
- 改前端必须 `scp` + `restart` + `Ctrl+F5`（服务端把 index.html 读进内存）。
- `#mascot-air` 必须放在看板娘 `<script>` 之前，否则 `getElementById` 拿到 null。
- 抠图脚本别管进 `| head`（SIGPIPE 会在第 40 帧杀掉进程）。
